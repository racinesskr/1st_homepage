# 와이즈만영재교육 하남센터

블로그 PDF를 바탕으로 제작한 홈페이지 초안입니다.

HTML/CSS/JavaScript 홈페이지. Vercel Framework Preset은 Other, 출력 디렉터리는 루트입니다. Vercel은 시간표 API에 필요한 패키지를 설치합니다.

## 시간표 운영

- 학부모용 주소는 `/schedule/`입니다. 공개한 수업이 요일과 시간 순으로 표시됩니다.
- 관리자 주소는 `/admin/schedule/`입니다. 로그인 후 수업을 추가·수정·삭제하고 **시간표 공개**를 누릅니다. 공개하기 전 편집 내용은 현재 탭에 있습니다.
- 첨부 이미지의 수업을 편집하려면 **11월 시간표 불러오기**를 누릅니다. 종료 시간은 필요한 경우에만 입력합니다. 여러 학년에 해당하는 수업은 대상 학년을 쉼표로 구분합니다.
- 처음에는 첨부 이미지의 11월 시간표가 표시됩니다. 관리자가 공개한 시간표가 있으면 그 내용이 표시됩니다.
- 시간표에는 과목, 대상 학년, 반 이름, 시간 등 공개해도 되는 정보만 입력합니다.

## Vercel 최초 설정

1. Vercel 프로젝트에서 비공개 Blob 저장소를 만들고 연결합니다. 서버에서 `BLOB_STORE_ID`와 Vercel OIDC 또는 `BLOB_READ_WRITE_TOKEN`으로 접근할 수 있어야 합니다. 미리보기에서 공개 기능을 시험할 경우 운영과 다른 저장소를 연결합니다.
2. Vercel 환경 변수에 `SCHEDULE_ADMIN_SETUP_CODE`를 추가합니다. 비밀번호 관리자에서 영문, 숫자, 하이픈, 밑줄로 구성된 32~128자의 임의 설정 코드를 생성하고 민감 정보로 저장합니다. 기존 `SCHEDULE_ADMIN_PASSWORD` 값도 설정 코드로 사용할 수 있습니다.
3. 배포한 뒤 관리자 화면에서 초기 비밀번호 `1234`를 입력합니다. 최초 설정 코드로 본인 확인을 하고 8자 이상의 새 비밀번호를 설정합니다. 이후에는 새 비밀번호로 로그인합니다. 설정 코드는 로그인 세션 검증에도 사용되므로 환경 변수에 유지합니다.
4. 수업을 등록하고 공개 페이지에 반영되는지 확인합니다. 시간표는 Blob의 `schedule/weekly.json`에, 비밀번호 검증값은 `schedule/admin.json`에 저장합니다.
